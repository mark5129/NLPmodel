Data Map Plots

We have tested different models for topic modelling. As statistical models we have LDA and NMF, which are harder to visualize, since they output bag of words for a number of topics.

Other than the statistical methods we are also investigating various Language models which can be used for topic modelling as well. They run differently since they embed each document in a multidimensional space this makes it possible to cluster the documents and visualize them in a 2D plot.
